%      below) to keep the 12 numeric columns inside the text width.

%   TSR  = task success rate (%)    Step = average steps per task
%   Inv  = average invalid actions (count; share of steps underneath)

%   Tok  = total (prompt + completion) tokens per task, in thousands

%   filled, worst case (4-digit tok)   \small + 4pt  485pt   fits

% numbers the rows are two lines high throughout, which also keeps the table
% uniform once the long numbers are filled in.

%   backbone with WingmanWM added (\emph{WM}).  TSR: task success rate.
%   Step: average steps per task.  Inv: average invalid actions, i.e.\ steps

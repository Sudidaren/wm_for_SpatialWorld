## 4. 评测口径（论文用）

- **TSR（官方口径）** = success / (success + failure)，`null` 不计入分母
- **Null rate** = null / total（API/env 故障；自动重试 2 次）
- **Completion rate** = success / total（保守口径）
- **SE_success** = 成功任务上 `mean(1 − steps / max_steps)`
- **SE_all** = success+failure 上 `mean(1 − steps / max_steps)`（失败任务
  触顶时贡献 0）
- steps = 官方 `step_count`（不含 init 动作）；单次运行（single run）
- 表格模板见 `docs/evaluation_section_draft.md`

## 5. 关键修复与证据（为什么这套代码可信）

1. **ai2thor 判定键缺失（核心）**
   - 官方 evaluator 读 `success_conditions`（复数键）+ `success_logic`；
     官方 ai2thor `load_task_from_folder` 只写单数键并把 list 塞进去 →
     evaluator 抛异常、`perform_final_evaluation` 静默返回 0 → **所有任务恒判
     失败**（昨天 312 个 false 全部无效）。
   - 官方 VirtualHome 加载器本来就做同一归一化；ProcTHOR 走完整 task.json。
     补丁仅补齐 ai2thor 缺失的键，不改变任务成功条件。
   - 证据：补丁前 golden 重放 `env._check_done=True` 但 evaluator=0；补丁后
     evaluator=1.0。冻结校验 3/3 golden 任务 Completed=true；官方 LLM 路径
     Gemini 跑 ai2thor05523 = Completed=true（steps=2）。
2. **agent 启动卡死（已修）**
   - 官方基底配置 `enable_subgoal_decomposition=true` 且 planner 指向
     `localhost:11435`（本地无该服务）→ agent 第一步一直等，表现为"卡在
     Starting task execution"。
   - 冻结版默认关闭子目标分解；若开启，planner 复用主模型（`eval_config.py`
     中 `ENABLE_SUBGOAL_DECOMPOSITION` / `PLANNER_FROM_MAIN_MODEL`）。
3. **RL/golden 判定传参 bug（已修）**
   - 官方 `perform_final_evaluation` 在 `state` 非空时用
     `state['config']['task']/['env']/['observation']` 覆盖入参；此前只传了
     config.task，导致 evaluator 拿到空配置恒判 0。已在 `rl_agents.py` 修正。
4. **防挂死机制**：子进程注入 `VLM_API_TIMEOUT=120`（每次请求硬超时）、
   600 秒无输出看门狗（杀进程组并整任务重试）、每个 attempt 输出
   `run_stream.log` 便于定位。
5. **VirtualHome（未纳入冻结声明）**：本地 WSLg 下官方启动器返回 HTTP 502
   （batchmode 与 windowed 均试过）；VH 端口已按任务分配（crc32 → 8100+），
   供修复后并行使用。修复前 **VH 结果不得进论文**。

## 6. 如何运行 / 切换

```bash
cd eval_pipeline
bash verify_freeze.sh            # 冻结自检：golden 3 任务必须全 true

# 纯 Gemini 全量（冻结版，当前正在跑）
bash run_gemini_438_frozen.sh

# 单任务调试
OPENAI_API_KEY=... OPENAI_BASE_URL=... \
  python supervisor.py --scenes ai2thor --profile llm --task ai2thor05523 --no-verify
```

模型/任务/场景都在 `eval_config.py`：

| 目标 | 配置 |
|---|---|
| 纯 Gemini | `PROFILE="llm"`，`LLM_PRESET="gemini-3.1-pro"` |
| 纯 Qwen | `LLM_PRESET="qwen3.5"` + `LLM_OVERRIDES={"model_name":"qwen3.5-397b-a17b"}`（MaaS 网关） |
| WingmanWM+LLM | `PROFILE="wingman_llm"`（仅 AI2-THOR+ProcTHOR=438） |
| RL 策略 | `PROFILE="rl"` + `RL_POLICY_IMPORT`（空=golden 自检） |
| 场景选择 | `SCENES=["ai2thor","procthor"]` / 加 `"virtualhome"` |

API：当前 `OPENAI_API_KEY`/`OPENAI_BASE_URL` 指向 ohmygpt 网关
（`apic1.ohmycdn.com`），Gemini 与 GPT-5 均可用；模型 id 必须小写
`gemini-3.1-pro-preview`。另有一把阿里云 MaaS key 可调 Qwen 系
（`qwen3.5-397b-a17b`、`qwen3.8-max` 等，支持视觉输入）。
